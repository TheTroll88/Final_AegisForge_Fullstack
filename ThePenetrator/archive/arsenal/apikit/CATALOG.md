# APIKit — Java API Security Testing Toolkit
# Source: C:\Users\natha\v4w_website\APIKit

## OVERVIEW
Maven-based Java project for API security testing and analysis.
Integrates with Burp Suite and XRay for active/passive scanning.

## BUILD
- Build system: Maven (pom.xml)
- Assembly: assembly.xml (JAR packaging)
- IDE: IntelliJ IDEA (APIKit.iml)
- Bundled dep: soa-model-core-1.6.4-SNAPSHOT-patched (SOAP/REST model parsing)

## CAPABILITIES (from screenshots)
- API discovery and enumeration
- Active scanning for API vulnerabilities
- Burp Suite integration (xrayburp.png)
- XRay security scanner integration (xray.png)
- Request payload analysis (req.png)
- Dashboard with scan results (dashboard.png)
- Configuration management (config.png)
- Multi-language support (APIKit_ch.png Chinese, APIKit_en.png English)
