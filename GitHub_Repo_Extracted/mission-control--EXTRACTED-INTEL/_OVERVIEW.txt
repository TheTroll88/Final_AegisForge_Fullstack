## WHAT THIS IS
The world's first autonomous product improvement engine. It's a Next.js 14
dashboard that orchestrates AI agents through OpenClaw Gateway to:
  Research → Ideate → Swipe → Build → Test → Review → PR — fully automated.

## WHY IT MATTERS TO AEGISFORGE
- It connects directly to YOUR OpenClaw/Chief at ws://127.0.0.1:18789
- It uses the SAME agent orchestration pattern as your Foreman/Logos
- It gives you a VISUAL DASHBOARD for all agent activity
- It has a full REST API your agents can call to report work
- PM2 process management (you need pm2 installed — on your todo list)

## TECH STACK
- Next.js 14 (React 18, TypeScript 5)
- SQLite via better-sqlite3 (no external DB needed)
- Zustand state management
- Tailwind CSS
- Playwright (browser testing by agents)
- OpenClaw Gateway WebSocket client
- PM2 for production process management
- Docker support (Dockerfile + docker-compose.yml)
