# AegisSignal (ASIG) Token Site

Simple static website for ASIG token information and official links.

## Contents

- `index.html` - Single-file site with inline CSS and contract copy button.

## Token Details

- Contract: `0x30610a21764bb38c43a2e532cfba91c9db927994`
- Chain: Base
- Supply: 1,000,000 ASIG
- Decimals: 18

## Local Preview

1. Open `index.html` in VS Code.
2. Use Live Server to preview locally.

## Deployment (GitHub Pages)

1. Push repository to GitHub.
2. Go to repository Settings -> Pages.
3. Set Source to `Deploy from a branch`.
4. Select `main` branch and `/ (root)` folder.
5. Save and wait for Pages URL.
